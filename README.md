# 🎲 داگز موج بات

ربات تلگرام بازی با تاس، بولینگ و دارت — با سیستم شرط‌بندی «داگز».

![Banner](banner.png)

## ✨ امکانات

- 🎲 سه بازی: **تاس** / **بولینگ** / **دارت**
- 🎯 سقف ۳ پرتاب در هر بازی
- 🤖 بازی با ربات یا 👥 بازی با دوستان
- 💰 سیستم شرط‌بندی (حداقل ۷۰ / حداکثر ۳۰۰۰ داگز)
- 💸 برداشت از موجودی (حداقل ۲۰۰۰ داگز)
- 🎁 سیستم زیرمجموعه
- 🔒 عضویت اجباری در کانال‌ها
- 🛠 پنل ادمین کامل

## 🚀 نصب

```bash
git clone https://github.com/USERNAME/dicex-wave-bot.git
cd dicex-wave-bot
pip install -r requirements.txt
cp .env.example .env
# .env رو ویرایش کن و توکن بذار
python main.py
```

## ⚙️ متغیرهای محیطی

| نام | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از @BotFather |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها (با کاما جدا) |
| `BANNER_FILE` | مسیر عکس بنر (پیش‌فرض: `banner.png`) |
| `BANNER_URL` | لینک عکس بنر (اختیاری، اولویت بالاتر) |
| `DB_PATH` | مسیر دیتابیس (پیش‌فرض: `dicex.db`) |

## 🎮 نحوه بازی

توی گروه بنویس:

```
1 تاس 100
2 بولینگ 500
3 دارت 1000
```

بعد از ساخت بازی، یکی از این دو حالت رو انتخاب کن:
- 🤖 **بازی با ربات** — تو اول پرتاب می‌کنی، بعد ربات
- 👥 **بازی با دوستان** — تو اول پرتاب می‌کنی، حریف بعد
